# KrushnaVardhanReddy's Homebrew Tap

Official Homebrew tap for [Krushna Vardhan Reddy's](https://github.com/KrushnaVardhanReddy) open-source software.

## Available Software

| Name | Type | Platforms | Description | Install Command |
| :--- | :--- | :--- | :--- | :--- |
| **[PaperPilot Desktop](https://usepaperpilot.com)** | Cask (GUI) | macOS | Local-first, privacy-focused open source PDF studio GUI | `brew install --cask KrushnaVardhanReddy/tap/paperpilot` |
| **[PaperPilot CLI](https://usepaperpilot.com)** | Formula (CLI) | macOS & Linux | Pure Rust high-speed PDF manipulation engine CLI | `brew install KrushnaVardhanReddy/tap/paperpilot` |
| **[OSMCP](https://github.com/KrushnaVardhanReddy/osmcp)** | Formula (CLI) | macOS & Linux | Open-source Model Context Protocol CLI & utilities | `brew install KrushnaVardhanReddy/tap/osmcp` |

---

## Quick Start

### PaperPilot Desktop App (macOS)
```bash
brew install --cask KrushnaVardhanReddy/tap/paperpilot
```

### PaperPilot CLI (macOS & Linux)
```bash
brew install KrushnaVardhanReddy/tap/paperpilot
```

### OSMCP
```bash
brew install KrushnaVardhanReddy/tap/osmcp
```

## Updating Installed Packages
```bash
brew update
brew upgrade
```
