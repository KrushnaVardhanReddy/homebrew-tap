# KrushnaVardhanReddy's Homebrew Tap

Official Homebrew tap for [Krushna Vardhan Reddy's](https://github.com/KrushnaVardhanReddy) open-source software.

## Available Software

| Name | Type | Description | Install Command |
| :--- | :--- | :--- | :--- |
| **[PaperPilot](https://usepaperpilot.com)** | Cask (GUI) | Local-first, privacy-focused open source PDF studio and document manipulation toolkit | `brew install KrushnaVardhanReddy/tap/paperpilot` |
| **[OSMCP](https://github.com/KrushnaVardhanReddy/osmcp)** | Formula (CLI) | Open-source Model Context Protocol CLI & utilities | `brew install KrushnaVardhanReddy/tap/osmcp` |

---

## Quick Start

### PaperPilot Desktop App
```bash
brew install KrushnaVardhanReddy/tap/paperpilot
```

Or tap explicitly first:
```bash
brew tap KrushnaVardhanReddy/tap
brew install --cask paperpilot
```

### OSMCP
```bash
brew install KrushnaVardhanReddy/tap/osmcp
```

## Updating Installed Packages
```bash
brew update
brew upgrade
```
